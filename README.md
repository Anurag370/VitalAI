# Contributing to the Project
(Fork and then clone your repo from your own github account)
## 1. Clone the repository

```bash
git clone <repository-url>
cd <project-directory>
```

## 2. Create a branch

```bash
git checkout -b feature/my-change
```

## 3. Make your changes

Edit the project files as needed, then check what changed:

```bash
git status
git diff
```

## 4. Install dependencies

Use the project's documented package manager. For example:

```bash
npm install
```


## 5. Commit your changes

```bash
git add .
git commit -m "Add description of change"
```

## 6. Push your branch

```bash
git push -u origin feature/my-change
```

## 7. Open a Pull Request

Open a pull request from your branch to the project's main branch and describe your changes.

### Before submitting

* Keep changes focused and easy to review.
* Always pull code before editing and pushing
* Use clear commit messages.
* Follow the project's existing coding style.
* Update documentation when necessary.
